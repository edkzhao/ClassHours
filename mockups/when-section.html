The WHEN section — three designs

Same panel width as the real one (404pt), so spacing is honest. The duration dropdowns are live — change one and watch the end time, including past midnight. Click a card to mark your pick.

Cross-midnight solves itself. Once duration replaces the end time, 23:00 for 2h 00m is unambiguous — it ends at 01:00 the next day, and there is no way to express it wrongly. The panel shows +1d so it is never a surprise. In Custom, where you type both ends, an end earlier than the start is read as the next day rather than rejected — the only sane reading.

The real question: two sessions that follow no pattern

One Saturday, one the following Wednesday at noon, both in a single series. Today's WHEN is built entirely around weekly repetition, so it cannot say this. Below are three ways out — they differ in what the common case costs, since most entries are still a plain weekly block.

One idea instead of two. Fill from a pattern… expands Mondays and Thursdays into real rows you can then edit or delete individually — so a term with one moved class is fixed in place. The cost is real: a 24-week course becomes 24 rows to scroll, where today it is one line. The second row shows a class running past midnight.
